## Packages
framer-motion | Essential for page transitions, scroll animations, and interactive elements
react-scroll | For smooth scrolling navigation between portfolio sections
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind CSS classes safely

## Notes
The portfolio is a single-page application with smooth scrolling sections.
Static assets like profile pictures should be placed in `client/public/images/`.
API endpoints are read-only public data for the portfolio content.
