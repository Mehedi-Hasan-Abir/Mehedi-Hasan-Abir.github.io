Scoring Hazari Round by Round: One Full Game to 1,000, Worked Through

A complete eight-deal Hazari game added up deal by deal, with every running total, so you can see how scores build and how the game ends.

Published November 24, 2026.

Hazari scores are easy to understand and easy to get wrong over an evening. This is one complete game, every deal added up, so you can follow the numbers from the first deal to the winning total.

I generated the game with the Hazari engine, with four computer players. Each deal's points are what each player collected, and every deal adds up to 360.

The game, deal by deal

Each line shows the points collected in that deal, then the running totals for Players A, B, C and D.

  1. Deal 1: 185, 0, 0, 175. Totals: 185, 0, 0, 175.
  2. Deal 2: 270, 90, 0, 0. Totals: 455, 90, 0, 175.
  3. Deal 3: 0, 0, 265, 95. Totals: 455, 90, 265, 270.
  4. Deal 4: 280, 0, 80, 0. Totals: 735, 90, 345, 270.
  5. Deal 5: 0, 80, 85, 195. Totals: 735, 170, 430, 465.
  6. Deal 6: 180, 0, 90, 90. Totals: 915, 170, 520, 555.
  7. Deal 7: 0, 0, 85, 275. Totals: 915, 170, 605, 830.
  8. Deal 8: 175, 0, 185, 0. Totals: 1,090, 170, 790, 830.

Player A reached 1,090 in Deal 8 and won. Notice what happened along the way.

What the numbers show

  • Every row adds up to 360. Deal 5, for example, is 0 + 80 + 85 + 195 = 360. If a row does not, someone miscounted.
  • Points come in lumps. A round winner takes every card in the round, so a player often collects 0 or 85 or 270 and rarely a number in between.
  • The leader can lose it. After Deal 6, Player A was on 915 and Player D on 555. After Deal 7 Player D had 830, and Player A, who scored nothing in Deal 7, still led by 85.
  • You can finish above 1,000. Player A won with 1,090 because the last deal added 175, not just the 85 needed.

What if two players pass 1,000 together?

Two players can pass the target in the same deal. The usual way to settle it is that the higher total wins. Agree on this before you play, because tables differ. The house rules checklist covers it.

Keeping the running score

  1. After each deal, write each player's points on one row.
  2. Add the row. It must be 360.
  3. Add each player's points to their previous total, in a separate row, and check that the totals add up to 360 times the number of deals. After Deal 8 the totals add to 2,880.
  4. Stop when a total reaches 1,000.

That last check is a good one. In this game the four totals after eight deals are 1,090 + 170 + 790 + 830 = 2,880, which is 8 × 360, so nothing went missing along the way.
