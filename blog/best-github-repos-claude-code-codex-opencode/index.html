15 Best GitHub Repos for Claude Code, Codex and OpenCode

This is my quick reference for the 15 repos in 15 GitHub Repos That Turn Claude Code, Codex and OpenCode Into a Real Team, which I published in Towards AI. The full article explains each repo and its catch. This page is the short version: what each one does, which agents it supports, and the install command.

The surprising part is that most of these are not software. They are folders of plain Markdown that tell a coding agent how to work, and they now sit among the most-starred projects on GitHub.

What an agent skill is

A skill is a folder with one instruction file, SKILL.md. The agent reads only its short description at startup and loads the full instructions when a task matches. The format is open, so the same skill usually works in Claude Code, OpenAI's Codex CLI and OpenCode. Most install with one line, npx skills add owner/repo, and Claude Code also has its own plugin marketplace.

The 15 repos at a glance

Planning: make the agent think before it types

  • obra/superpowers (about 310K stars): a strict workflow of design first, small tasks, tests before code and proof before "done". Install in Claude Code with /plugin install superpowers@claude-plugins-official.
  • mattpocock/skills (about 308K): grill-me questions your plan until it is clear, and handoff compresses a session so a fresh session or another agent can continue. Install with npx skills@latest add mattpocock/skills.
  • multica-ai/andrej-karpathy-skills (about 228K): a single CLAUDE.md with four rules against silent guessing, over-building and editing code you never asked about.

Memory and token cost

  • affaan-m/ECC, formerly everything-claude-code (about 294K): agents, skills, hooks, rules, memory and security scanning in one kit for Claude Code, Codex, OpenCode and Cursor. Take the parts you need.
  • thedotmack/claude-mem (about 108K): summarises what the agent did and feeds the relevant parts into later sessions. Install with npx claude-mem install.
  • JuliusBrussee/caveman (about 117K): makes the agent answer in fewer words. Its README reports about 65% fewer output tokens on average. Install with npx skills add JuliusBrussee/caveman.

Design

  • nextlevelbuilder/ui-ux-pro-max-skill (about 143K): styles, colour palettes and UX rules the agent consults before it writes CSS. Use one design skill per project.

Diagrams and code understanding

  • tt-a1i/archify (about 92K): architecture, sequence and data-flow diagrams as one HTML file, with PNG and SVG export. Install with npx skills add tt-a1i/archify -g.
  • Egonex-AI/Understand-Anything (about 89K): turns a codebase into an interactive knowledge graph you can search and question. On Codex the command is $understand.
  • cathrynlavery/diagram-design (about 64K): publication-style HTML and SVG diagrams that can match your brand. Install with npx skills add cathrynlavery/diagram-design.

Plumbing and directories

  • farion1231/cc-switch (about 152K): a desktop app that switches API providers and manages MCP servers, skills and prompts across agents.
  • code-yeongyu/oh-my-openagent (about 71K): turns OpenCode into an orchestrator with parallel specialist agents.
  • vercel-labs/skills (about 37K): the npx skills installer itself. Run it with --list to preview a repo first.
  • anthropics/skills (about 186K): Anthropic's official skills, the best example of what a well-made skill looks like.
  • hesreallyhim/awesome-claude-code (about 57K): a curated directory of skills, agents and plugins for further reading.

Star counts are a snapshot from around 1 November 2026. Stars measure popularity, not quality or safety.

Which three to install first

  • Starting out: the Karpathy rules, Matt Pocock's skills and the npx skills installer.
  • Long sessions: Superpowers, claude-mem and caveman.
  • Explaining code to people: archify, Understand-Anything and diagram-design.

Check a skill before you install it

  • Read the SKILL.md. A skill is an instruction your agent will follow.
  • Open any bundled scripts and look for network calls.
  • Prefer pinned versions over the latest commit.
  • Install a few skills you understand rather than dozens. In one Vercel test, an available skill went unused in 56% of default cases.

The takeaway

The most-starred AI tools this year are habits written in plain text: plan first, remember what happened, say less and show your work. You can adopt those habits even without installing a single package.
