12 Claude Skills for Slides, Reports and Marketing

12 free, open-source Claude skills that build slide decks, reports, landing pages, videos and marketing copy from plain-English requests, with no coding needed.

This is a quick reference for 12 GitHub Repos That Turn AI Into Your Slide, Report and Marketing Team (No Coding Needed), Part 2 of my series in Towards AI. Part 1 was for developers. This list is for marketers, founders, consultants, teachers and analysts who work in PowerPoint, Excel and the browser.

Every repo here is a skill or skill pack: plain-text instructions that teach Claude, Codex or OpenCode how to do one job well. If you can type a request into a chat box, you can use them.

How to install a skill without writing code

  1. Paste the link. In Claude Code or the Code tab of the Claude desktop app, paste the repo's GitHub link and write "Install this skill" followed by the link.
  2. Paste one line. Most repos give a command starting with npx skills add. The same line installs the skill for Claude Code, Codex and OpenCode.
  3. Upload a zip to Claude.ai. Zip the skill folder and add it in the Skills settings, with code execution switched on.

The 12 repos by job

Slides, reports and spreadsheets

  • anthropics/skills (about 181K stars): Anthropic's official skills create and edit Word, Excel with real formulas, PowerPoint and PDF files, including PDF forms. The four document skills are source-available rather than fully open.
  • zarazhangrui/frontend-slides (about 27K): animated, well-designed decks that run in the browser. It shows style previews first and can convert an existing PowerPoint. The output is a web page, not a .pptx file.
  • nexu-io/open-design (about 90K): a desktop app that turns your agent into a design studio for prototypes, landing pages, dashboards, slides and video, with export to HTML, PDF, PPTX and MP4.

Web pages, design and video

  • nextlevelbuilder/ui-ux-pro-max-skill (about 135K): a searchable library of styles, palettes, font pairings and usability rules for building a whole site.
  • Leonxlnx/taste-skill (about 95K): design variants such as minimalist, brutalist and soft, useful for redesigning a page that looks generic. Use one design skill per project.
  • heygen-com/hyperframes (20K+): describe a video and the agent renders it to MP4. It runs on your own computer and needs Node.js and video tools, so it is the most technical item here.

Marketing, SEO and writing

  • coreyhaines31/marketingskills (about 58K): about fifty MIT-licensed skills for copywriting, conversion, SEO audits, email sequences, ads, pricing and launches. Install with npx skills add coreyhaines31/marketingskills.
  • AgriciDaniel/claude-seo (about 4K): a smaller SEO-only toolkit for auditing a site and its content.
  • blader/humanizer (about 56K): rewrites drafts to remove obvious AI writing patterns. It fixes style, not facts.

Research, notes and discovery

  • mvanhorn/last30days-skill (about 64K): a brief of what people said about a topic in the last 30 days on Reddit, Hacker News, GitHub and Polymarket.
  • kepano/obsidian-skills (about 49K): lets the agent read, link and write notes inside an Obsidian vault.
  • ComposioHQ/awesome-claude-skills (about 75K): the largest curated directory of Claude skills, plus a plugin that connects to many apps.

Star counts are approximate, from public snapshots between mid-2026 and early November 2026.

If you only install three

Start with anthropics/skills, marketingskills and humanizer. Together they cover the files you hand to people, the marketing thinking behind them and the voice they are written in. Add a design skill when you need a web page and a video skill when video is the deliverable.

Stay safe

  • Popular does not mean safe. An NVIDIA analysis of more than 31,000 public skills, as reported by Walma AI, found vulnerabilities in about a quarter of them.
  • Before installing, ask your agent to read the skill and say whether it sends data anywhere or runs anything hidden.
  • Install two or three skills, not twenty. Overlapping skills compete with each other.
