How I Built an Offline Hazari Scoring App Friends Can Watch Live

Why scoring Hazari on paper goes wrong, and how I built a free offline scorekeeper in English and Bangla with a read-only live scoreboard you share by link.

Tags

  • Card Games
  • Progressive Web App
  • React

  • Bangladesh

Published November 21, 2026.

Hazari is a card game that runs for many rounds. Every round, each player's points are added to a running total, and the first to reach the target wins. By default I use a target of 1000 and 360 points shared in each round.

Keeping that score on paper or in a phone note is where the arguments start. A number is copied wrong, a round is added twice, and nobody can say who is really ahead. I built a scorekeeper to fix exactly that, and you can use it free at hazari-card-game-scoring.vercel.app.

What the app does

  • Scores the game for you. Enter each player's points for the round on a large keypad. The app adds the totals, ranks the players and shows how far each one is from the target.
  • Works offline. Once it has loaded, you can score with no connection. Games, rounds and recent player names are saved on your own device.
  • English and Bangla. The whole interface is available in both, with an optional switch to Bangla digits.
  • Installs like an app. It is a progressive web app, so you can add it to your phone's home screen.
  • Lets friends watch live. Start sharing and send a link. Everyone who opens it sees the leaderboard update as you save rounds, and no one else can change a score.

Design choices that mattered

A keypad you can use with one hand

Scoring happens at a table, often with a card in the other hand. So the keypad fills the remaining screen height, the buttons are at least 48 pixels, and the Next and Save buttons stay in a fixed place. There is a Fill button that completes the last player's score from what remains of the round total, and a one-tap Undo for a mistaken round.

A check that doesn't get in the way

A round should add up to the round total. When it doesn't, the app asks you to confirm before saving instead of blocking you, because house rules differ and sometimes the scorer knows better. Putting that choice in a dialog also means the keypad never moves while you type.

Rules kept apart from the interface

The scoring rules live in a small TypeScript module with its own unit tests, separate from the screens and the storage. That made it safe to change the interface many times without touching how points are counted.

Local first, then sharing

Scoring never needs an account or a server. Saved games live in the browser's IndexedDB. The only part that uses the cloud is live sharing, and it starts only when you choose to share. By default you share as a guest; signing in with Google is optional.

A shared link is read-only and can be switched off. Viewers see a live leaderboard with who is leading and who deals next, plus small highlights such as a winning streak. The scorer's phone stays the single source of truth.

Playful tags

Because Hazari is a game among friends, the leaderboard teases players. From the third round, each player gets a short tag based on their position, in English or Bangla, such as a boast for the leader and a friendly roast for whoever is last. The tag only changes when a new round is saved.

How it is built

  • React 19 and TypeScript, built with Vite.
  • Dexie on IndexedDB for saved games, so scoring works without a network.
  • A service worker that caches the app, so it reloads offline.
  • Firebase only for the optional live scoreboard.
  • Zod to validate data that comes from backups and shared links.
  • Unit tests for the scoring rules and browser tests for the main flows, including offline use and accessibility.

What it does not do

It is a scorekeeper, not a card game. It does not deal cards or play against you. Hazari rules also differ between regions, so the app follows a standard four-player rule set with an adjustable target and round total. If your table plays differently, change the numbers when you start a game.

Try it

Open the Hazari scoring app, start a game, and share the link with your table. The site also has short guides on how to score Hazari and the rules of the game, in English and Bangla.
